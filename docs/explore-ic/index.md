## 集成电路是什么

集成电路（Integrated Circuit，IC）是在半导体材料上制造大量器件，并通过互连把它们组成电路的技术。日常说的“芯片”通常指封装后的集成电路产品，但芯片不只有 CPU：手机里的射频收发器、汽车中的功率管理芯片、相机中的图像传感器，也都属于这个世界。

本篇面向还没修过专业课的同学。先建立“器件—电路—系统”的坐标，再决定去学设计、器件、体系结构，还是设计自动化。这里的入门定位参考 [NJU 集成全家桶](https://njuic-students.github.io/) 和 [IC 自学指南](https://crys-chen.github.io/ic-guide/)，上科大课程则单独依据学院官方材料整理。

### 从一个开关到一台计算机

**晶体管（Transistor）**可以用一个端口的电压控制另一条通路中的电流。把它近似成开关，就能理解数字逻辑；研究电流随电压连续变化的规律，就进入模拟电路。它不是无损、瞬时的理想元件：每次切换都需要时间和能量，也会受到噪声、温度与制造偏差影响。

从晶体管到系统，可以分为几个抽象层：

| 层次 | 关心什么 | 例子 |
| --- | --- | --- |
| 器件与工艺 | 电流如何产生，结构如何制造 | MOSFET、介质层、金属互连 |
| 电路 | 器件怎样组合，速度和噪声如何 | 反相器、触发器、放大器 |
| 逻辑与微架构 | 每个时钟周期完成什么工作 | 状态机、流水线、缓存 |
| 片上系统 | 计算、存储、通信与接口如何协作 | CPU、加速器、总线、外设 |
| 产品与软件 | 实际任务如何运行，系统如何供电散热 | 手机、服务器、汽车电子 |

片上系统（System on Chip，SoC）把多个功能模块集成到同一芯片；它不等于“一个更大的 CPU”。有些模块是数字逻辑，有些是模拟接口，还有存储、电源和时钟。理解这些边界，才能看懂为什么一块芯片需要不同专业的人协作。

### 摩尔定律与后摩尔

摩尔定律（Moore's Law）概括了集成电路中晶体管数量随时间增长的历史趋势，不是必须兑现的物理定律。很长一段时间里，缩小器件尺寸能够提高集成度，并与电压缩放一起带来速度、成本和能效的改善；今天，这些收益不再自动同时出现。

短沟道效应、漏电、互连延迟、功耗密度，以及制造和设计成本，使“换一个更先进节点”不能独自解决所有问题。后摩尔时代因此不仅研究更小的晶体管，也研究专用加速器、三维集成、先进封装、新型存储与光电融合。**后摩尔不意味着硅 CMOS 已经失效，而是系统进步需要更多条技术路径。**具体例子见 [前沿技术速览](/explore-ic/frontier)。

### 为什么重要

芯片决定了系统可以多快、多省电、多便宜地感知和计算。数据中心关心算力和供电；可穿戴设备关心电池寿命；医疗与汽车电子还需要考虑可靠性、测试和长期供货。芯片设计的目标通常是满足约束，而不是孤立追求最高频率。

功耗、性能、面积（Power, Performance, Area，PPA）是一组常见指标，但真正的产品还要考虑开发周期、良率、封装、软件生态和成本。一个算法在电脑上可运行，不代表它已经变成可制造的芯片；一个 RTL 仿真通过，也不代表流片后的电路一定工作。

### IC 相关专业到底学什么

- **数学与编程**：建立模型、分析随机性、实现算法和自动化工具。
- **物理与器件**：理解材料、载流子、晶体管和制造约束。
- **电路与信号**：分析电压电流、频率响应、反馈和噪声。
- **数字与体系结构**：把行为描述转成并行硬件，理解计算与存储组织。
- **实现与实验**：做验证、版图、时序、测试与测量，让结果可重复。

不需要入学时就选定终身方向。做一个状态机、测一个放大器、阅读一份器件特性曲线，往往比先背熟所有岗位名称更有帮助。

### 在上科大从哪里开始

上科大信息学院的本科专业名称是**电子信息工程（EE）**。2026 级培养方案的目标覆盖半导体器件、集成电路与系统等领域，也覆盖电力、能源、自动化等方向，因此“EE”与“只学芯片”不能画等号。

对 IC 感兴趣，可以先抓住 SI100B 信息科学技术导论、EE111 电路基础、CS100 计算机编程，再在 EE115A 模拟电路、EE115B 数字电路、EE150 信号与系统、EE130 电磁学中建立基础。EE120 半导体器件基础在 2026 级方案中属于专业限选“三选二”的课程之一，并非所有 EE 学生都必须单独选这门课。
