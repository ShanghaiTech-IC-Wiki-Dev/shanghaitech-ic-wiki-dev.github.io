# 友链与资源入口

这里收录值得长期保留的入口，而不是尽可能多的链接。建议先确定一个问题，再选一门课程或一个项目深入；收藏数量不会自动变成能力。外站的课程版本、许可证和访问条件由原维护者决定，本站收录不代表合作关系或内容背书。

## 芯片开源生态与练习

| 资源 | 适合什么需求 |
| --- | --- |
| [一生一芯](https://ysyx.oscc.cc/) | 从数字逻辑、编程和处理器走向软硬件系统实践 |
| [一生一芯官方讲义](https://ysyx.oscc.cc/docs/) | 核对当前课程版本、阶段和任务，避免混用旧路线 |
| [OpenROAD](https://theopenroadproject.org/) | 了解开源数字芯片物理实现流程 |
| [CHIPS Alliance](https://www.chipsalliance.org/) | 查找开放硬件与相关软件工具生态 |
| [RISC-V International](https://riscv.org/) | 进入开放指令集规范与官方生态信息 |
| [HDLBits](https://hdlbits.01xz.net/) | 通过小题练习 Verilog 与数字逻辑 |
| [Yosys](https://yosyshq.net/yosys/) | 学习开源逻辑综合工具 |
| [Verilator](https://www.veripool.org/verilator/) | 了解 RTL 仿真与模型编译工具 |

开源工具不意味着工艺资料都可公开，开源项目也各有许可证。运行公开 RTL、实现版图和真正完成流片是不同层次，不能相互替代作为能力证明。实操路线见[开源 EDA](/tools/open-source/)与[一生一芯介绍](/competitions/projects/ysyx)。

## 公开课程与实验平台

| 资源 | 可学习的内容 | 访问与使用提醒 |
| --- | --- | --- |
| [清华大学计算机国家级实验教学中心](https://lab.cs.tsinghua.edu.cn/) | 数字逻辑、组成原理等实验平台与教学信息 | 文档公开不代表远程硬件或评测账号向校外开放 |
| [南京大学计算机系统基础实验（ICS PA）](https://nju-projectn.github.io/ics-pa/) | 通过模拟器和运行时理解程序与系统 | 按课程版本阅读，不以抄现成解答替代实现 |
| [Nand2Tetris](https://www.nand2tetris.org/) | 从逻辑门到完整计算机的基础路线 | 可作系统入门，不等同于工业芯片设计流程 |
| [MIT OpenCourseWare](https://ocw.mit.edu/) | 数学、物理、电子与计算机公开课程 | 根据先修选内容，注意教材与视频版本 |
| [Berkeley CS61C](https://cs61c.org/) | 计算机组成、RISC-V 与系统基础 | 实验平台与自动评测政策按当期规定 |

如果发现失效链接，欢迎通过[参与共建](/community/contributing)附上原链接、问题和可靠替代入口。推荐新资源时，请说明适合人群、先修要求以及它能解决什么问题；优先官网和维护稳定的项目，不收录盗版教材、破解工具或泄露课程答案。
