# 上海 IC 企业地图

上海的集成电路产业覆盖设计、制造、工具、IP、封装与测试。地图的用途是帮助你了解生态与寻找岗位，不是企业排名，也不意味着所列企业当前都有学生岗位。公司可能有多个办公与生产地点，注册地址、总部、面试地点和实际工作地点不能混为一谈。

## 先按片区建立空间感

下表只将有公开地址依据的例子放入片区，不把所有公司强行归到张江。

| 片区 / 地址线索 | 可核实的企业例子 | 阅读地图的方法 |
| --- | --- | --- |
| 张江 / 浦东 | 紫光展锐上海总部、芯原张江总部；华虹相关制造基地 | 设计、IP 与制造相互关联，但具体岗位和厂区仍要分别核对 |
| 临港 / 南汇新城 | 芯原官网列出的海港大道办公点 | 同一企业可能同时在张江与临港有办公点；以具体岗位地址为准 |
| 徐汇漕宝路 / 漕河泾周边 | 澜起科技官网列出的漕宝路总部 | 不要把“漕河泾周边”当成精确园区边界，面试前核对楼宇 |
| 上海其他园区与多地点 | 下表中的设计、EDA 和封测企业 | 招聘页面可能按上海市列示，再向招聘方确认实际地点 |

片区只能辅助估算通勤与生活安排，不能从“在同一个园区”推断公司之间有合作，也不能从总部地址推断所有实习都在那里。

## 从公司清单到投递清单

1. 先选[岗位方向](/career/employment/)，写出自己能提供的能力证据。
2. 从企业官网进入校园招聘页面，筛选城市、学历、届别和岗位要求。
3. 记录投递日期、岗位编号、实际地点、面试状态和是否有排他承诺。
4. 对照工作内容补项目与基础，不批量投递互不相关的职位。
5. 接受意向前核对合同、培养安排、保密与知识产权，不依赖口头保证。

薪资、招聘人数和转正比例均以当年信息为准，本站不做待遇排名。企业名录也不构成推荐或合作背书。
