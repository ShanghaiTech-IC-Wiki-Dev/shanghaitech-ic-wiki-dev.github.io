# IC 岗位图谱

“做芯片”包含许多不同工作。岗位名在企业间并不统一，前端、架构、验证、实现和软件也可能交叉。选择岗位时先读实际职责、交付物和协作关系，再看工具列表；会打开软件不等于掌握工程方法。

## 设计与实现岗位

| 岗位 | 常见工作与技能栈 | 面试常见问题方向 |
| --- | --- | --- |
| 数字前端设计 | 微架构、RTL、逻辑综合；Verilog / SystemVerilog、时序逻辑、脚本 | 状态机、流水线、握手、时钟域跨越、复位、可综合性；为什么这样设计？ |
| 数字验证 | 制定验证计划、搭建环境、回归与覆盖率；SystemVerilog、UVM、断言、参考模型 | 激励与检查如何闭环、随机约束、功能覆盖与代码覆盖、定位失败的方法 |
| 可测性设计（DFT） | 扫描链、自动测试向量生成、存储器自测试；测试原理与时序约束 | 故障模型、覆盖率、可控可观测性、扫描时钟与测试开销 |
| 数字后端 / 物理设计 | 布图、布局、时钟树、布线与签核；Tcl、静态时序分析、物理约束 | setup / hold、时钟偏斜、拥塞、压降、工艺角、时序与功耗面积取舍 |
| 模拟 / 混合信号设计 | 放大器、数据转换、时钟与电源等；器件物理、反馈、噪声、SPICE | 偏置、小信号、稳定性、噪声与失配、PVT、指标之间的权衡 |
| 模拟 / 定制版图 | 匹配、寄生、电源和可靠性；布局规则、DRC、LVS、寄生提取 | 共心与对称、护环、寄生反馈、天线效应、设计与版图如何协同 |
| 芯片架构 / 系统架构 | 需求建模、性能与带宽预算、软硬件划分；体系结构、工作负载、建模工具 | 瓶颈定位、性能模型、存储层次、互连、如何证明架构收益能落地 |

前端工程师也要理解时序和物理限制，验证工程师也要理解设计意图，后端工程师也需要读懂约束来源。不要把岗位分工误解为知识可以完全割裂。

## 器件、制造与生态岗位

| 岗位 | 常见工作与技能栈 | 面试常见问题方向 |
| --- | --- | --- |
| 器件研发 / 建模 | 器件结构、表征、紧凑模型或 TCAD；半导体物理、数值分析、实验 | 能带、载流子、短沟道效应、参数提取、模型与测量偏差 |
| 工艺研发 / 工艺整合 | 单步工艺与流程集成、良率和可靠性；材料、工艺、统计与实验设计 | 光刻 / 刻蚀 / 沉积基本原理、过程窗口、缺陷、如何设计对照实验 |
| 封装 / 测试 | 封装互连、热与可靠性、量产测试；电学测量、测试脚本、统计 | 信号完整性、热管理、测试覆盖、良率、量测重复性和异常定位 |
| 现场应用工程师（FAE） | 客户方案支持、调试与技术沟通；器件或系统应用、仪器、文档 | 如何复现客户问题、区分器件与系统原因、解释规格并推进解决 |
| EDA 研发 | 综合、布局布线、仿真、验证或分析工具；C++、数据结构、图算法、优化、数值方法 | 算法正确性与复杂度、内存与性能、约束建模、基准公平性、回归测试 |

EDA 应用工程师与 EDA 研发工程师的侧重点不同：前者更关注工具部署、流程、客户设计与问题定位，后者通常更强调算法及软件实现。IP 企业也可能同时招聘设计、验证、物理实现与应用支持岗位。

## 把课程项目转成岗位证据

选择一到两个项目做深，而不是为每个岗位快速拼一个演示。至少保留：需求说明、结构图、个人贡献、测试计划、失败案例、结果与复现步骤。数字设计可沿[数字路线](/learning/digital-ic/resources)深入，模拟和器件分别参考[模拟路线](/learning/analog-ic/resources)与[器件路线](/learning/devices-and-process/resources)，EDA 参考[算法路线](/learning/eda/resources)。

面试准备可以按三层展开：

1. **基础**：不用工具也能解释核心概念，画出电路、时序或数据流。
2. **项目**：解释设计取舍、个人工作、验证范围与最困难的问题。
3. **工程**：讨论可维护性、异常输入、资源限制、协作和交付，而不是只谈最佳指标。

没有用过某款商业工具，可以诚实说明学过的等价流程与可迁移知识，不声称“熟练掌握”。不会的问题，先说明条件再推理；背诵术语并不能替代理解。

## 比较 offer 时看什么

看具体团队与业务、培养与反馈机制、岗位内容、地点、劳动合同、保密与竞业条款，以及书面确定的薪酬结构。**薪资以当年为准**，不根据单个传闻给岗位或企业排名；不同学历、城市、团队与招聘批次不能直接横向比较。

企业地图见[上海 IC 企业](/career/employment/companies)，投递准备见[实习指南](/career/internship/)。职业发展可以跨岗位，但转向通常需要补齐对应的作品和工程知识，不是只改简历标题。
