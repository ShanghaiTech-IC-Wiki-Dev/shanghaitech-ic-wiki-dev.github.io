# 实习准备与信息渠道

实习的目标不是提前获得一张“大厂门票”，而是了解真实工程流程、验证岗位兴趣，并积累可解释的协作经验。能进入什么项目、接受怎样的指导，往往比企业名气更影响收获。

## 什么时候开始找

具备相关基础并能保证连续投入后就可以关注岗位，但不要只凭年级决定。低年级可先完成课程项目与公开训练；有数字电路、编程或器件基础后，再对照岗位描述（Job Description，JD）补齐短板。模拟设计、器件研发等岗位可能更看重高阶课程或研究经历。

暑期实习和转正实习常有集中招聘，日常实习可能全年开放。作为准备建议，可在目标开始时间前 2–4 个月建立投递清单；这不是企业统一日程。每周到岗天数、连续月数、学校审批和导师安排应在面试前说清，不为了进入流程承诺无法兑现的出勤。

## 上科大的信息入口

信息学院官网的“实习就业”栏目下分设**实习信息、就业信息、企业导师**等入口。[实习信息栏目](https://sist.shanghaitech.edu.cn/2844/list.htm)可作为校内线索来源，但列表包含往年通知，看到企业名不等于当前仍有空缺。应核对发布日期、招聘届别、职位地点和企业最新官网。

也可留意学院宣讲与实训通知，结合[培养项目](/shanghaitech/programs)判断是否存在特定项目的实习安排；不能把项目介绍中的合作资源当成面向所有学生的岗位保证。2026 年学院集成电路暑期实训提供数字工具和项目实操训练，但训练证书不等同于录用资格。

其他可靠渠道包括企业招聘官网、正规校园招聘平台、公开技术活动及经允许的师友推荐。内推只是一种投递渠道，不应为“保 offer”支付费用，也不应把个人证件交给不明中介。

## 先选岗位，再改简历

| 实习方向 | 建议展示的能力证据 |
| --- | --- |
| 数字前端 / FPGA | 可综合 RTL、时序理解、模块接口与测试记录 |
| 验证 | 测试计划、激励与检查机制、覆盖率思路、失败定位 |
| 后端 / DFT | 约束理解、时序分析、流程脚本、测试与可测性基础 |
| 模拟 / 版图 | 电路原理、仿真条件、PVT 分析、DRC / LVS 概念 |
| EDA 软件 | C++ / Python、算法与数据结构、性能分析和测试 |
| 器件 / 工艺 / 测试 | 物理基础、实验规范、数据处理、可靠性意识 |

更完整的岗位要求见[岗位图谱](/career/employment/)。不要把同一份简历同时投所有方向：保留共同基础，调整最相关项目的顺序与描述。

## 简历与项目介绍

学生简历通常以一页清楚表达为目标，而不是硬性格式要求。突出教育背景、相关技能、两三个有深度的项目与可公开成果。项目条目按“做什么 → 个人负责什么 → 如何验证 → 结果与限制”写。

“完成 CPU”过于笼统；更有价值的是解释 ISA 范围、流水线结构、验证方法、时序或资源结果，以及遇到的一个真实 bug。数字必须有测试条件，不把仿真频率当成硅片实测。不能把组内成果、开源作者贡献或未授权商业项目写成个人独立实现。

面试前准备简短介绍和深入讲解两版，能回答设计取舍、接口、边界条件、验证不足及如何改进。技术细节记不清时，说明核验方式，不临时编造。

## 接受实习前核对什么

- 工作内容、指导人、到岗时间、地点、报酬结算方式和请假制度。
- 实习协议、保密与知识产权条款，以及学校要求的审批手续。
- 课程、科研与企业工作是否存在时间或成果归属冲突。
- 岗位是否真正提供学习与工程参与机会，是否要求不合理付费。

实习期间保留自己的工作记录，但不得把企业网表、代码、PDK、客户资料或内部日志带回公开仓库。结束时可与指导人讨论哪些成果允许写入简历；能展示工程方法，不等于能公开工程文件。具体薪资与福利以当年岗位和书面约定为准。
