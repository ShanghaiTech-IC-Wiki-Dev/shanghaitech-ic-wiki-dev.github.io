# 专业方向

选择学习方向时，可以先问自己最想解释哪一类问题。

- [工艺与器件](../devices-and-process/index.md) · 从制造步骤理解单个器件的电学特性。
- [电路](../circuits/index.md) · 从器件与逻辑单元出发，分析电路怎样处理信号。
- [系统架构](../computer-architecture/index.md) · 研究处理器、存储和互连怎样配合。
- [算法与编程](../algorithms-and-programming/index.md) · 将问题写成程序，验证结果并评价效率。
- [EDA](../eda/index.md) · 用算法和软件自动完成芯片设计任务。
