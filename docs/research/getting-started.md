# 本科生科研入门

科研不是把课程项目做得更大，而是围绕一个尚未解决的问题，提出解释或方法，再用可信证据检验它。对本科生而言，最重要的收获常常不是第一篇论文，而是学会读原始资料、定位问题、设计对照实验，以及把失败讲清楚。

## 为什么做，何时开始

如果你想判断自己是否适合读研究生、希望理解课堂知识如何变成芯片，或对某个现象持续好奇，都值得尝试。不要仅为简历上的一行经历进组，也不要把“没有论文”理解为没有收获。

年级不是唯一门槛。低年级可以从听讲座、补基础和复现小实验开始；掌握电路、编程或器件基础后，再承担边界清楚的子任务。信息学院本科招生介绍明确提到，本科一年级起就有机会进入课题组，但这不代表每个组随时有名额，也不意味着越早越好。先保证课程与生活有稳定余量，再与老师讨论适合自己的入口。

## 如何找老师

1. 先看[科研方向地图](/explore-ic/research-directions/)，选出两三个真正想了解的问题。
2. 在[教授与课题组](/shanghaitech/faculty/)查公开方向，进入主页读近期论文。至少能用自己的话说出一篇论文解决了什么。
3. 写简洁、有针对性的邮件：自己的专业与年级、相关课程或项目、感兴趣的具体问题、可投入的时间，并附精炼简历。不要群发同一段赞美，也不要附未经授权的课程答案或组内资料。
4. 面谈时讨论任务、指导方式、阶段目标、设备权限和预期投入，而不只是问“能不能发论文”。邮件未回复不等于拒绝；可间隔一段时间礼貌跟进一次。

联系前可准备一页项目说明：问题、你负责的部分、结果、失败案例、代码或公开演示。没有科研经历时，一个能解释清楚的课程项目比堆砌工具名更有用。

## 进组后通常做什么

| 阶段 | 常见任务 | 有价值的交付物 |
| --- | --- | --- |
| 熟悉问题 | 阅读综述、学习工具、理解已有设计 | 术语表、问题地图、读书笔记 |
| 建立基线 | 运行公开代码、复现电路或测量流程 | 固定版本与配置、日志、偏差说明 |
| 承担子任务 | 写测试、改模块、整理数据、搭建测量 | 可复现脚本、测试记录、失败分析 |
| 提出改进 | 明确假设、设计对照、分析代价 | 对照实验、消融结果、适用边界 |
| 整理表达 | 组会汇报、图表、文档或论文 | 可追溯的结论与下一步 |

“跑通”不等于“复现成功”：工艺、频率、工作负载、精度、随机种子和测量范围都可能改变结论。进展记录至少包含本周问题、做过的尝试、证据位置、未解决项和下次第一步。汇报坏消息要及时，提问时附最小复现与已排查内容。

## 与课程如何平衡

把考试、课程项目和科研节点放进同一张日历。先与指导者约定可持续的每周投入，期中和期末提前说明减量，不要靠连续熬夜兑现不现实的承诺。一次只保留一个主问题；遇到新方向先记录，不立即开新坑。课程基础薄弱时，补好先修课往往比同时读十篇前沿论文更有效。

## 上科大可以利用什么

- **本硕博一体化课程体系**：学院公开介绍强调由导论、基础、专业到高阶课程的递进关系。可结合[课程导航](/shanghaitech/courses/)寻找研究所需知识；本科生选修研究生课程的资格、先修和学分认定以教务规定为准。
- **集成电路暑期实训**：2026 年通知覆盖 Cadence 数字工具和 RISC-V 项目实操，面向有先修基础的学生，高年级优先；该年度实训不计课程学分。它适合补齐工程流程，不应被当成自动获得科研或流片资格。
- **学院学术讲座与交流**：从报告题目、问题背景和提问环节入手，不必要求第一次就听懂全部细节。具体场次、报名和参与范围查学院公告。
- **实验与计算平台**：先阅读[平台资源](/shanghaitech/research-groups/)，完成培训和授权后使用；开放资源不等于可以共享账号、绕过预约或外传工艺资料。
