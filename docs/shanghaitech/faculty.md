# 教授与课题组

本页数据以**信息学院师资库，2026 年 11 月核对版本**为主，结合《后摩尔器件与集成系统中心》介绍材料和课题组公开主页整理。教授职称、研究重点和招生安排可能变化，**以学院与课题组当前公布为准**；本页不是招生名额表，也不对导师或实验室进行排名。

四个方向簇沿用本站科研方向分类，而非学院行政划分。分方向卡片按每位老师的「主方向」展示，避免在多个小节重复出现；交叉方向仍保留在卡片标签中。要找一位老师，既可以从问题出发读 [科研方向](/research/)，也可以直接看页面后部的完整名单。

::: tip 怎么读这份名单
先用方向缩小范围，再点开主页阅读近期论文。一个标签只能概括部分工作：例如光计算同时涉及光子器件与计算架构，硬件安全同时涉及电路与系统。没有出现在某个分节，不代表该老师不做这方面研究。
:::

## 器件与工艺

这个方向簇从材料和物理机制出发，关心「什么器件能做出来、它有什么特性、怎样连接到系统」。上科大相关研究覆盖自旋电子与磁存储、宽禁带半导体、光电子与集成光子、微机电系统（Micro-Electro-Mechanical Systems，MEMS）及柔性电子。许多课题横跨器件设计、微纳加工和测量，选组前应同时了解实验技能与理论先修；平台入口见 [科研与工艺平台](/shanghaitech/platforms)。

### 半导体器件与新型存储

从磁性、自旋、低温与宽禁带材料等不同机制切入，理解器件如何实现存储、开关、传感或新型计算。方向导读：[半导体器件与新型存储](/research/devices)。

<FacultyList dir="devices" primary />

### 光电子与集成光子

包括光电探测与激光器、光子集成电路、非线性及量子光子学，也与光计算和智能感知交叉。方向导读：[光电子与集成光子](/research/photonics)。

<FacultyList dir="photonics" primary />

### MEMS、传感与柔性电子

关注微纳尺度的机电耦合、压电器件、传感与柔性器件，并连接医疗、机器人和射频应用。方向导读：[MEMS、传感与柔性电子](/research/mems-sensors)。

<FacultyList dir="mems" primary />

## 电路设计

这个方向簇把器件能力变成能工作的电路，并以功耗、性能、面积及实际应用约束评价设计。上科大的公开方向既包括数字专用芯片和 FPGA，也包括脑机接口、医疗电子、电源管理、无线传能以及射频电磁。应用导向很鲜明，但「做某种应用芯片」仍需要相应的电路基础、设计工具和验证方法，不能只学上层算法。

### 模拟、混合信号与生物医疗芯片

重点连接数模混合电路、植入式医疗电子与脑机接口芯片。方向导读：[模拟与混合信号](/research/analog-mixed)。

<FacultyList dir="analog" primary />

### 电源管理与功率电子

从芯片电源管理到功率变换和能量收集，连接电路、宽禁带器件应用及电气系统；相关老师分布于智慧电气科学中心等平台。方向导读：[电源管理与功率电子](/research/power)。

<FacultyList dir="power" primary />

### 射频、微波与电磁

涵盖天线、微波电路、电磁波调控与成像，与器件、医疗和人工智能辅助设计交叉。方向导读：[射频、微波与电磁](/research/rf-em)。

<FacultyList dir="rf" primary />

### 数字 VLSI 与专用芯片

数字超大规模集成电路（Very Large Scale Integration，VLSI）研究连接算法、硬件架构、RTL 和物理实现，可进一步面向视觉、图形与可重构计算。方向导读：[数字 VLSI 与专用芯片](/research/digital-vlsi)。

<FacultyList dir="digital" primary />

## 系统与架构

这个方向簇问的是「计算如何组织，怎样高效而可信地运行」。上科大相关研究既有后摩尔中心的先进计算电路与 AI 硬件，也有系统与安全中心的体系结构、存储系统、高性能计算和系统安全。它与数字电路相邻，但常需要更完整的编程、操作系统和性能分析背景；同一个加速器问题也可能从电路、架构或系统软件三个层次切入。

### AI 芯片与新型计算

关注低比特、动态随机计算、边缘 AI 等计算电路与系统问题。光计算、存算一体等交叉工作还可在器件和光子学分节中找到。方向导读：[AI 芯片与新型计算](/research/ai-hardware)。

<FacultyList dir="ai-hw" primary />

### 计算机体系结构与系统

从处理器与存储到高性能计算，研究硬件组织和软件系统之间的相互约束。方向导读：[计算机体系结构与系统](/research/architecture)。

<FacultyList dir="arch" primary />

### 硬件安全与隐私计算

包括隐私计算芯片、侧信道、可信执行环境和微架构安全；应区分电路级攻击面与系统级威胁模型。方向导读：[硬件安全与隐私计算](/research/hardware-security)。

<FacultyList dir="security" primary />

## 设计方法学

电子设计自动化（Electronic Design Automation，EDA）研究设计工具与算法，而不只是使用商业软件。上科大公开方向覆盖 AI4EDA、设计空间探索、物理设计、可制造性设计和计算光刻，并与硬件安全、集成电路及光电混合计算交叉。适合既愿意理解芯片约束、又愿意钻研算法与软件实现的同学；做工具也需要知道工具最终优化和验证的对象是什么。

### EDA 与可制造性设计

方向导读：[EDA 与可制造性设计](/research/eda)。建议结合电路与设计流程课程，理解评价指标、基准设计和算法复杂度，再阅读方法论文。

<FacultyList dir="eda" primary />

## 如何联系老师、参与课题组科研

以下是通用建议，不代表任何课题组的录取条件或招生承诺。

1. **先读公开材料。** 阅读老师主页、近期两三篇论文的摘要和图表，写出自己真正想了解的问题。不需要第一封邮件就提出成熟研究方案，但要能说明为什么对这个方向感兴趣。
2. **让邮件简短、可回复。** 标题写明「本科科研咨询 / 年级 / 方向」；正文说明学术背景、已修课程、相关项目、每周可投入时间和希望开始的时间。附简历或项目链接，提出一个明确请求，如是否有适合本科生的科研任务或能否预约交流。
3. **按任务准备先修。** 数字芯片可从 [EE115B](/courses/ee115b)、[EE113](/courses/ee113) 与 HDL 入手；模拟方向重视 [EE115A](/courses/ee115a) 和电路分析；器件方向重视物理、半导体与实验安全；系统和 EDA 方向还需编程、算法与数学。先修建议应由具体导师进一步确认。
4. **讨论可交付的小任务。** 本科科研常见起点包括论文复现、测试脚本、仿真与测量、模块实现、读书讨论和毕业论文。先确认目标、指导方式、时间安排与数据使用规则，再逐步扩大范围。
5. **区分科研参与与招生。** 短期参与课题组，不自动等于保研、硕博录取、流片资格或论文署名。涉及实验设备、许可证和非公开数据时，必须遵守培训授权与保密要求。
