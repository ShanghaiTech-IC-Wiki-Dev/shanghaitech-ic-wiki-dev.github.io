# 上科大课程总览

选课先看三层信息：**你的年级培养方案决定毕业要求，教务系统决定实际开课与选课资格，课程大纲决定当学期内容和考核。** 本页把它们与 IC 学习路线连接起来，不替代任何一层正式文件。

## 数据来源与适用范围

下方课程表整理自 **2026–2027 学年 SIST 官方开课表**，聚焦 IC 及相关基础、体系结构、人工智能和 EDA 课程，并非学院全部课程。教师、学分、学期与先修信息均采用该学年数据。官方表明确说明开课存在不确定因素、更新可能不及时，**最终以教务系统为准**。

详细经验页主要依据维护者的 **2026 春 / 秋版本课程笔记**与公开课程主页重写。往届版本教师可能与当前开课表不同；不把旧班级的评分比例、作业题目或软件版本当作下一学年的承诺。

::: warning “必修”必须结合专业与年级理解
课程表中的课程类型不能独立用来判断你的毕业要求。例如 CS110 在开课数据中标为必修，但不在下列 2026 级 EE 专业必修清单中。跨专业选课、学分归类与替代关系须核对本人培养方案。
:::

## 2026 级 EE 本科培养方案要点

### 至少 143 学分怎样组成

| 类别 | 必修 | 选修 | 小计 |
| --- | --- | --- | --- |
| 人文社科通识 | 31 | 22 | 53 |
| 自然科学通识 | 28 | 2 | 30 |
| 专业课程 | 32 | 19 | 51 |
| 任选课程 | — | — | 9 |
| **总计** | | | **143** |

SI100B 归入自然科学通识的信息课程群，不在专业课程的 32 学分中重复计算。英语、体育、课程群与实践要求也要逐项核对，不能只用总学分相加判断毕业资格。

### 专业限选：三选二

本学科选修共 **19 学分**，其中专业限选至少 **8 学分**：**EE140 通信原理、EE120 半导体器件基础、EE160 控制原理**三门各 4 学分，至少选两门，方案建议在三（1）/ 三（2）修读；多选的学分计入本学科选修的 19 学分，不是额外再加一套限选额度。该限选要求标为推免前必修。

选择可结合方向：器件与 IC 设计关注半导体基础，信号链与无线系统关注通信，反馈系统与电力电子关注控制。方向兴趣不免除培养方案要求。

### 推免前不只检查专业课

方案还将相关数学、物理及实验、SI100B、化学 / 生物课程群指定选课，以及多项思政和通识必修标为推免前必修。建议大三前按教务系统逐项核对；“已选但未结课”与“已满足要求”不是一回事。推免资格和具体审核时间另见学校当年通知及[推免准备](/career/graduate-study/baoyan)。

## 典型四年选课节奏

培养方案提供两张课程分布图，主要差别是模拟 / 数字电路与信号与系统的先后，以及电磁学、部分通识的安排。下表保留两条可选节奏，不把分布图中有排版差异的每学期小计当作固定负荷。

| 学期 | 分布图路径 A | 分布图路径 B / 安排重点 |
| --- | --- | --- |
| 大一秋 | 线性代数、数分 I / 高数 I、SI100B，配合军事、英语、体育与通识 | 核心专业基础相同；先建立数学与数字系统直觉 |
| 大一春 | 数分 II / 高数 II、普通物理 I 及实验、EE111 + EE111L | 路径 B 同期还安排经济学导论；关注实验与理论配合 |
| 大一暑期 | 暑学期课程；暑假安排国家安全教育、社会实践 | 按当年具体组织方式参加 |
| 大二秋 | EE150 + EE150L、概率统计、普通物理 II 及实验、化学 / 生物选课 | 路径 B 改为 EE115A + EE115B，信号课程后移 |
| 大二春 | EE115A + EE115B、CS100，以及人文写作等 | 路径 B 安排 EE150 + EE150L、CS100、EE130 + EE130P |
| 大二暑期 | 暑学期课程；暑假安排产业实践 | 若参加芯片实训，提前准备 Linux 与电路基础 |
| 大三秋 | 限选三选二、EE130 + EE130P、专业选修 | 路径 B 已完成电磁学，可分配给专业选修；核对推免前必修 |
| 大三春 | 专业选修，配合思政与体育 | 围绕方向补课，避免多个大型项目同时从零启动 |
| 大三暑期 | 暑学期课程 | 按实际安排连接科研、实践与毕业课题准备 |
| 大四秋 | SI99 毕业论文启动 / 推进、体育健康相关要求 | 核查所有课程群、学分类别与毕业缺口 |
| 大四春 | 持续完成毕业论文及毕业要求 | 不能把所有欠修与毕业设计集中到最后几周 |

这是培养方案的阅读辅助，不是自动生成的个人课表。更多先后修关系可参考[数字路线](/learning/digital-ic/)、[模拟路线](/learning/analog-ic/)与[器件路线](/learning/devices-and-process/)。

## 研究生课程与本研共享

学院提供本硕博课程体系与课程图谱，因此本页也收录 EE219、EE291F、CS290U、EE213、EE215A 等研究生课程，帮助本科生规划进阶。这里的“本研共享”指**把课程放进连续的学习网络中查看和规划**，不意味着所有研究生课对本科生无条件开放，也不意味着自动计入本科专业选修或研究生培养学分。

选课前确认：是否允许本年级修读、先修是否满足、是否需要教师同意、学分如何认定、实验资源是否覆盖本科生。尤其注意实验与课程设计可能独立设课、独立考核；页面合并介绍不等于选课时合并注册。
