# EE115A 模拟电路

<CourseTable codes="EE115A" />

课程表为 **2026–2027 学年**安排；下文经验主要来自 **2026 春版本**笔记。往届版本教师可能不同，内容与考核以当学期课程大纲为准。

## 课程定位

如果电路基础教你如何列基尔霍夫方程，模拟电路进一步回答：如何让晶体管在合适的偏置下，把一个很小的信号可靠地放大。官方先修为 EE111；建议同时熟悉复数阻抗、节点分析和一阶电路响应。

本课把[器件与工艺](/explore-ic/devices-process)连接到[模拟学习路线](/learning/analog-ic/)。后续可学习 EE112 模拟集成电路 I，再进入运放、数据转换与模拟信号链。不要把“会代增益公式”当作已掌握设计：偏置、工作范围和非理想效应同样重要。

## 内容主线

2026 春笔记可整理成“先看系统，再拆到器件，最后重新组合”的结构：

| 阶段 | 知识内容 | 应能回答的问题 |
| --- | --- | --- |
| 导论与放大器抽象 | 增益、输入输出阻抗、带宽；理想与非理想运放 | 虚短成立需要什么条件？饱和后还能使用吗？ |
| 半导体与 PN 结 | 载流子、漂移与扩散、二极管特性 | 电路模型对应什么物理机制？ |
| MOSFET 与小信号 | 工作区、直流偏置、跨导与输出电阻 | 小信号模型在什么工作点附近成立？ |
| 单级与偏置 | 共源、共栅、共漏；电流镜 | 增益、摆幅与阻抗如何取舍？ |
| 复合放大器 | 共源共栅、差分对、有源负载 | 高增益需要牺牲什么电压余量？ |
| 运放与反馈 | 两级结构、负反馈、带宽与稳定性概念 | 闭环性能由哪些开环参数限制？ |

每道分析题建议先写直流工作点，再画小信号模型，最后检查计算出的输出是否仍在有效范围。脱离工作区直接套用模型，是比代数错误更隐蔽的问题。

## 实验 / 项目

2026 春资料记录的 Research Project 是三选一综述：无线神经刺激器、能量采集用超低压 DC-DC、超低功耗运放。要求形成至少 5 页的 IEEE 格式报告，主线为文献综述、现有方法比较与可选的新思路。

超低功耗运放题目可围绕低电压余量、小电流下的跨导效率，以及噪声、带宽和负载之间的权衡展开。比较论文时先对齐工艺、电源、负载与测量条件，**仿真结果、实测结果与定性设想分列**。没有运行电路仿真，就不要把推测写成验证结论。

本页没有足够材料确认独立模电实验课的完整安排，不据此宣称本课包含固定的实验学分。若希望补充动手能力，可用获授权的 SPICE 环境验证偏置和小信号预测；是否属于正式交付以课程通知为准。

## 往届经验与建议

**2026 春版本。** 笔记确认有持续作业、考试与综述项目，但没有完整可靠的总评比例，因此本页不估算各项权重，也不沿用旧考试的携带资料规定。

- **难点**：从器件参数切换到整级等效参数；差模与共模不能混用；高增益不等于拥有足够的输入输出摆幅。
- **准备**：把 EE111 的节点电压法与戴维南等效复习熟练。学习新拓扑时，分别记录“偏置怎么来、信号怎么走、限制在哪里”。
- **作业**：推导完再用数量级和极限情形检查，例如负载变大、输出电阻有限时，结果是否合理。
- **项目**：先核验文献，再组织比较表；不要把不同负载下的带宽或不同电源下的功耗直接排名。
- **工具链**：手算用于解释，SPICE 用于核验；保存模型版本、分析类型和输入条件，不能只留下波形截图。
