# EE115B 数字电路

<CourseTable codes="EE115B" />

课程表采用 **2026–2027 学年**开课信息；经验为 **2026 春版本**。往届版本教师可能不同，作业语言和考核以当学期大纲为准。

## 课程定位

本课把[SI100B](/shanghaitech/courses/si100b)中的门电路直觉推进为可分析、可描述和可验证的数字系统。官方先修为 EE111；学习上建议先熟悉二进制、基本电路量与逻辑门。

它是[数字集成电路 I](/shanghaitech/courses/ee113)、FPGA、嵌入式系统与[智能计算系统](/shanghaitech/courses/ee219)的重要基础，也与[CS110](/shanghaitech/courses/cs110)的数据通路章节相互补充。两门课有重合不等于可以互相替代：本课重点是逻辑和电路，体系结构更关注指令与系统组织。

## 内容主线

2026 春笔记呈现以下学习顺序，具体讲次可能随班级调整：

1. **表示信息**：数制转换、二进制运算、编码与检错。明确位宽和符号规则，再计算结果。
2. **表达与化简逻辑**：布尔代数、真值表、卡诺图与 Quine–McCluskey 方法；比较两级与多级实现。
3. **搭建组合模块**：加法器、算术逻辑单元（ALU）、编码译码器、多路选择器、比较器，以及冒险现象。
4. **学习硬件描述语言（Hardware Description Language，HDL）**：理解 VHDL / Verilog 的结构、并行语义、仿真与测试平台，而不是逐行“执行程序”。
5. **引入状态**：锁存器、触发器、移位寄存器、计数器；建立与保持时间、复位和时钟。
6. **描述系统行为**：有限状态机（Finite State Machine，FSM）、Moore / Mealy 模型、状态编码与寄存器传输级（RTL）实现。
7. **连接实际硬件**：CMOS、存储器与存储扩展，以及模数 / 数模转换基础。

学习关键是把“功能正确”和“时序正确”分开检查：真值表正确并不能证明某个寄存器在目标时钟下能稳定工作。

## 实验 / 项目

2026 春项目为 **Subway Turnstile Controller**：用 Moore FSM 分阶段实现闸机控制器，从正常通行扩展到双传感器、反向闯入报警和超时保护。项目使用 Verilog、Icarus Verilog（`iverilog`）与 GTKWave，要求用状态图和波形解释实现。

项目内部评分为四个模块各 20 分、报告 20 分，总计 100 分；**这是项目内部配分，不是课程总评占比**。这里介绍任务类型，不提供可直接提交的 RTL。

可迁移的设计方法是：先将文字要求变成状态与转移条件，再列出同时输入时的优先级，最后为复位、计数边界、异常输入和正常通行分别构造测试。对于安全相关行为，不能只验证“人顺利走过”这一条路径。

## 往届经验与建议

**2026 春版本。** 可确认有作业和状态机项目，但完整总评比例未由现有笔记可靠给出；本页不补造考试、实验或出勤权重。

- **难点**：组合逻辑与时序逻辑的语义、非阻塞赋值、复位行为，以及计数器的差一拍问题。
- **准备**：每学一种模块，都先写输入输出定义和预期行为，再写代码。不要通过反复改 `always` 块“试到波形看起来对”。
- **工具链**：先完成编译、生成 VCD、打开波形的最小闭环；错误发生时同时查看输入、状态、计数器和输出，而非只看最后一个端口。
- **交付**：报告逐项关联状态图、实现意图与波形证据。按任务书组织文件，不能假设评测会自动寻找任意目录下的模块。
- **诚信**：2026 春项目笔记记录了禁止使用 AI 代写 RTL 的要求；新学期须重新确认政策。允许使用工具辅助理解，不代表允许代写或代交。
