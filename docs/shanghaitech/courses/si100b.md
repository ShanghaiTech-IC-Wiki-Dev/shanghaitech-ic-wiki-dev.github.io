## 课程定位

SI100B 是信息科学的入门窗口。在 2026 级 EE 培养方案中，它属于自然科学通识的信息课程群，建议大一秋修读。EE 部分让你第一次把“计算”理解成可搭建的硬件，而不只是屏幕上的程序。

官方开课表未列先修要求。开始前会基本进制转换、能按步骤检查逻辑条件即可，不必提前学完整本芯片教材。之后可接[数字电路 EE115B](/shanghaitech/courses/ee115b)，也能为[计算机体系结构 CS110](/shanghaitech/courses/cs110)中的数据通路建立直觉。更长的路线见[数字学习地图](/learning/digital-ic/)。

## 内容主线

公开课程页的 **2026 秋 EE Lectures** 按以下顺序展开：

| 讲次 | 核心内容 | 学习检查点 |
| --- | --- | --- |
| 1 | 导论 | 说明数字系统怎样表示和处理信息 |
| 2 | 逻辑门与组合逻辑 | 从真值表得到组合功能，区分输入与输出 |
| 3 | 数制 | 对齐位宽、有符号数和编码的含义 |
| 4 | 算术电路 | 将加法等运算分解为可连接的模块 |
| 5 | 存储与时序逻辑 | 理解电路如何保存状态，以及时钟的作用 |
| 6 | 计算机系统 | 把运算、存储和控制连接为系统 |

不要把“画出来能亮灯”当作理解完成。应能解释一个输出来自哪条逻辑路径、寄存器何时更新，以及输入改变后哪些节点不应立刻改变。

## 实验 / 项目

公开页提供 Logisim-evolution 教程与课程版安装包。**2026 春版本**还公开了从基础作业、算术逻辑单元（Arithmetic Logic Unit，ALU）到 miniCPU 的资料。miniCPU 分为 Python 汇编器与 Logisim 电路两个子任务，配套材料涉及 RISC-V 背景、汇编、指令编码和微结构。

建议按“单模块 → 模块连接 → 指令行为”验证：先穷举小规模组合逻辑，再检查寄存器复位与更新，最后用短程序跟踪程序计数器、操作数和结果。保留能复现错误的最短输入，不要仅截取最终成功画面。具体题目与交付物以所选学期 Project Document 为准；春季项目不代表秋季必然使用同一任务。

## 往届经验与建议

**2026 春 / 秋版本。** 春季公开资料包含 miniCPU，秋季页面提供 EE 讲义与 HW0；页面注明秋季 HW0 不计入课程成绩。这只是某项作业的规则，不能推导出整门课程的评分比例；完整总评构成请查当学期大纲。

- **难点**：把程序的顺序执行与电路的并行传播区分开，尤其是位宽、进位、寄存器更新和控制信号。
- **准备**：先熟悉二进制、逻辑门、真值表；遇到汇编器任务再补 Python 字符串解析与数值处理。
- **工具链**：安装后先打开课程模板并完成一次小电路自测，确认文件能保存、重开、运行，再开始大型项目。
- **协作边界**：讨论电路原理与调试方法，不交换整份可提交电路；测试应由自己理解和解释。
