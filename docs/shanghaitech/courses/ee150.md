# EE150 信号与系统及实验

<CourseTable codes="EE150,EE150L" />

课程表使用 **2026–2027 学年**信息；经验主要对应 **2026 秋版本的一个班级**，并不代表所有班级。往届版本教师可能不同，考核以当学期大纲为准。

## 课程定位

信号与系统提供描述“输入怎样变成输出”的共同语言。它不仅用于通信和数字信号处理，也帮助理解模拟电路的频率响应、控制系统的稳定性，以及采样系统的限制。

官方先修为数学分析 II、线性代数。建议熟悉复数、欧拉公式、积分和等比级数；这些基础比提前背变换表更有用。后续可接 EE152 数字信号处理、通信原理和控制原理，也可与[模拟电路](/shanghaitech/courses/ee115a)对照学习。方向关系见[基础自学](/learning/fundamentals/)和[模拟路线](/learning/analog-ic/)。

## 内容主线

| 阶段 | 内容 | 重点区分 |
| --- | --- | --- |
| 信号与系统性质 | 连续 / 离散信号、冲激与阶跃、自变量变换、线性和时不变性 | 线性不等于时不变，因果不等于稳定 |
| 时域分析 | 线性时不变（Linear Time-Invariant，LTI）系统、冲激响应、卷积、微分 / 差分方程 | 连续卷积的积分区间与离散卷积的求和范围 |
| 周期与频域 | 傅里叶级数、连续与离散时间傅里叶变换、频率响应 | 离散时间频谱的周期性，与连续频率的量纲 |
| 时频联系 | 幅相响应、滤波、群延迟、一阶 RC 响应 | 仅看幅度不能完整判断波形失真 |
| 复频域与采样 | 拉普拉斯变换、z 变换、极零点、采样与混叠 | 收敛域影响系统解释，采样频率影响频谱重叠 |

最后一阶段属于课程笔记的总体知识地图；具体覆盖深度应查当学期完整课表。建议每学一个变换，都做一次“由定义求解”和一次“用性质快速求解”，而不是只记表格。

## 实验 / 项目

EE150L 是独立列出的 1 学分实验课，不能因理论课页面合并介绍就漏选或漏查实验要求。2026 秋笔记记录实验从第 2 周开始，但未提供足够完整的逐次实验任务与考核比例，因此本页不编排官方实验清单。

适合与理论配合的自练包括：数值卷积、观察一阶系统响应、比较不同采样率下的正弦信号，以及画滤波器幅相响应。这些是**学习建议，不是确认的课程作业**。可使用 MATLAB 或 Python 的 NumPy、SciPy 与 Matplotlib；若实验指定软件，应优先使用指定环境。

实验报告要写清采样间隔、时间范围、频率单位、归一化方式和边界处理。数值图像与手算不一致时，先排查连续积分与离散求和之间的缩放、截断和步长，而不是立即怀疑理论。

## 往届经验与建议

**2026 秋版本。** 一个班级的笔记记录总评为作业 15%、期中 30%、期末 50%、出勤 5%，其中两次考试为闭卷。该比例不能外推到其他班级，也不能当作 EE150L 的成绩构成。笔记还记录手写、英文作答与迟交规则，提交前须重新检查每次作业说明。

- **难点**：自变量变换顺序、卷积有效区间、冲激的尺度因子，以及不同变换的周期性和收敛条件。
- **准备**：复习复指数与等比级数；画图时先标支持区间，再计算交叠范围。
- **复习**：将 CT / DT、周期 / 非周期、时域 / 频域做成对照表。公式必须附适用条件，避免把傅里叶变换与拉普拉斯变换混用。
- **工具链**：用数值程序核查形状与数量级，但不能用一段绘图代码代替要求的推导和证明。
