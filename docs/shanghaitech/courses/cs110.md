# CS110 计算机体系结构 I 及课程设计

<CourseTable codes="CS110,CS110P" />

课程表采用 **2026–2027 学年**信息；详细内容与评分参照公开的 **2026 春版本**课程主页。往届版本教师可能不同，CS110 与 CS110P 需分别核对注册与考核要求。

## 课程定位

CS110 研究数字计算机如何组织和执行程序，把“代码能运行”推进到“为什么得到这个结果、时间花在哪里、硬件怎样实现”。官方先修为 CS100；学习时需要较扎实的 C 编程基础。

[SI100B](/shanghaitech/courses/si100b)与[EE115B](/shanghaitech/courses/ee115b)能提供硬件直觉，但课程并不是单纯的数字逻辑复习。它向后连接操作系统、并行计算，以及[EE219 智能计算系统](/shanghaitech/courses/ee219)。对于 EE 学生，应按本年级培养方案确认其学分归类，不因开课表写“必修”就视为 EE 专业必修。

## 内容主线

以下按 2026 春官网周历归并：

| 周次 | 知识主线 | 建议达到的能力 |
| --- | --- | --- |
| 1–2 | 信息表示、C、内存管理 | 解释整数与浮点表示，跟踪指针、栈和堆 |
| 3–4 | RISC-V、调用约定、编译汇编链接加载 | 从 C 行为对应到寄存器、指令和函数调用 |
| 5–6 | 数字逻辑、数据通路与控制器 | 沿单周期 CPU 跟踪一条指令 |
| 7–8 | 流水线与多发射 | 分析数据 / 控制冒险、转发和停顿 |
| 9–10 | 存储层次与高速缓存（Cache） | 分解地址，判断命中与缺失并计算平均访问代价 |
| 11–13 | SIMD、线程级并行、OpenMP、同步与多核 | 区分向量化、并行加速与同步开销 |
| 14–16 | I/O、虚拟内存、仓库级计算、可靠性与异构计算 | 把单核知识放回完整系统 |

性能分析应使用明确的工作量与时间口径。降低某段代码的指令数，不一定降低总执行时间；改变访存和并行策略时尤其如此。

## 实验 / 项目

CS110 的 Lab 与 CS110P 的 Project 在课程主页并列组织，但评分不同。2026 春课程设计包含多个分阶段项目；笔记记录了 CPU 性能优化与 Longan Nano 开发板实践。

**Project 4：Snake Game** 使用 C 与 RISC-V 汇编，借助 PlatformIO 交叉编译并烧录至 Longan Nano。项目要求独立完成，采用现场人工检查。重点不只是游戏画面，还包括指定的汇编逻辑、输入处理、状态切换及可重复构建。

建议先打通编译、烧录、按键与屏幕最小链路，再增加玩法；将状态更新和绘制分离，分别验证。最终必须从实际提交包重新构建，不能依赖工作目录里未提交的资源文件。实验与项目的具体限制、代码模板和检查标准以当学期任务书为准。

## 往届经验与建议

**2026 春版本。** 官网列出 CS110 总评：Homework 40%、Lab 5%、两次期中各 14%、期末 25%、参与 2%。CS110P 为 P/NP，Project 1.1 / 1.2 各 17%，2.1 / 2.2 各 16%，3 / 4 各 17%。这些是不同课程的两套考核，不应相加。

- **节奏**：作业占比较高且项目并行推进，不能只在考试前集中学习。
- **难点**：C 指针与内存错误、调用约定、流水线周期图、Cache 地址拆分和线程同步。
- **准备**：熟悉 Linux、Git、Makefile、调试器和交叉编译概念。出现错误时先定位到编译、链接、运行还是硬件接口阶段。
- **性能实验**：固定输入与线程数，先检查输出正确性，再报告时间；不能用一次偶然的最快结果代表稳定加速。
- **诚信**：个人项目独立实现；讨论原理与交换提交代码之间有明确边界。
